# 前端制作决定

> 历史原型记录。现行范围（0.3-review：主岛＋群岛、13 种实体、无同行、无跳跃升降键）以 [新规范入口](../docs/README.md) 为准。本文件保留当时的实现背景，不覆盖后续规则。

本文件记录创作者要求“先做前端”后的最新实现范围，优先于早期访谈中的建议。

- Lux3D 用于生成世界或 3D 资产，Codex 基于资产做游戏。后续更精细的资产可替换，撤回游玩期后台生成模型的建议。
- 正式引擎意向为 Unity。本机没有 Unity 编辑器，先做独立浏览器原型验证体验；当前交付是 Three.js 前端，不是 Unity Web 构建。
- 电脑浏览器、单人、第三人称，主体整体可辨认。统一操作为 WASD、鼠标、Shift、空格、Ctrl、R、E、Esc。
- 尺度变化由 R 化身触发，目标必须在当前尺度的可达范围内且可从局部辨认。镜头朝向结合距离选择一个目标，单个目标出现涟漪。
- 不设任务、死亡、失误或惩罚，保留想象力与自由移动。身体的动作和节奏应有差异，避免穿模。
- 不同尺度共享空间关系，原身体留在现场；移动岛屿或星球会携带依附事物，返回小尺度时保留变化。
- E 邀请／解除完全相同具体种类的同行者，最多三名。化身后原同行者留在原处恢复自然活动，解除跟随。
- 使用真实自然质感与克制的构图。远景以轮廓、光雾和色块组织，近处逐步呈现细节。当前临时几何与材质尚未达到最终美术标准。
- 首次短暂提示必要按键，完整操作放暂停菜单。偶发世界回应约 8–16 字，至少间隔 90 秒；探索路径通过环境表达。
- 前端支持独立 GLB 模型、真实骨骼动画的克隆和播放。草叶风动、物体平移可以使用程序动画；鸟鱼需根据实际资产验证 Aholo 或 Blender 的绑骨和动画产物。
- 自动保存当前身体、实体位移与同行状态；在同一浏览器站点中重入继续探索。

首轮浏览器检查已验证交互、尺度限制、同行边界、骨架独立性、动画播放与重载保存。它不替代最终美术、完整物理和 Unity 性能验收。
