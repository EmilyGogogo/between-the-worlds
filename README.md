# 万物之间 · Between the Worlds

一款以「成为万物」为核心的单人探索游戏。在草叶间、树冠下、水面与群岛之间，进入不同的身体，体验它们看见、听见和行动的方式，直到成为脚下的岛屿。

人只是万物中的一种存在。换一个身体与尺度，熟悉的世界也会显出另一种样子。

当前为 `0.4-review` 开发原型，面向电脑浏览器与键鼠，使用 Three.js 实现；最终引擎仍待 R-05 确认。设计规则见 [文档入口](docs/README.md)。

## 目标与范围

面向愿意观察自然、自由尝试的电脑端玩家，不需要游戏或哲学背景。美术采用自然比例、可信材质、柔和光雾与克制构图；声音以环境声为主，偶尔出现简短的中文回应。

当前按 3–4 人、2–3 周的 Demo 规模规划。首版范围以 G-04／G-05 为准，星球、太阳、房屋、花、同类同行、复杂生态、多人和运行时生成玩法进入 [DEFERRED](DEFERRED.md)。资产预留独立替换槽，至少一项核心资产须有真实 Lux3D 制作与游戏内验证证据；交付包括可运行链接或构建、真实运行视频、源码、报告与来源材料，详见 [提交清单](docs/10-submission-checklist.md)。

## 核心玩法

**观察目标 → 按 R 魂穿 → 以新的身体感知和移动 → 继续探索。**

- **成为不同的存在**：草、树、人、狗、鸟、鱼、岩石、岛屿，共 8 个类别，当前包含 11 种身体。
- **逐级跨越尺度**：身体分为近地、人身、林冠、地貌、群岛五个尺度档，每次只能成为本档或相邻档的存在；从草到岛要一级一级长大，或像鸟一样飞到高处才看得见整座岛。成为岛后观察群岛，也能逐级回到小尺度。
- **感受身体差异**：狗以黑白视野观察世界，鸟随视线飞行，鱼在水中游动；视野、雾感与听觉参数随身体变化。
- **探索自然环境**：一座主岛、三座邻岛与海，主岛包含草地、林地、山湖、岩丘和岸线。
- **触发轻量互动**：靠近时草会弯折，鸟会飞起并返回，鱼会四散；探索中偶尔出现简短的文字回应。

干净开局是人；沿尺度档逐级长大到巨岩，或成为鸟飞到足够高处，看到岛并选中它的涟漪，就能按 R 成为岛。目标体验是在 3–5 分钟内完成一次从人出发、到岛再回到小尺度的往返，之后可以继续漫游；这一体验目标仍需真人试玩验证。当前为单人游戏，多人指仓库的共同开发。

## 操作

| 操作 | 按键 / 方式 |
| --- | --- |
| 移动 | WASD |
| 环视 | 鼠标；未锁定指针时可按住拖动 |
| 加速 | Shift |
| 魂穿 | 看向可用目标，按 R |
| 暂停 / 继续 | Esc |

没有跳跃或独立升降键。鸟与鱼在移动时随视线俯仰升降；地面身体沿地表移动。暂停菜单可切换声音、重新开始，游戏会在当前浏览器保存进度。

## 本地运行

安装 Python 3.9 或更高版本，使用电脑端 Chrome 或 Edge。游戏依赖已随仓库提供，运行无需 Node、npm、API key 或在线下载资源。

从 Git clone 当前分支的完整源码后，Windows 双击根目录 `启动游戏.bat`，macOS 双击 `启动游戏.command`，保持终端窗口开启。浏览器会打开 [本地游戏](http://127.0.0.1:4173/)。

也可以在仓库根目录依次执行：

```sh
python3 project/sync_runtime.py
python3 frontend/serve.py --open
```

Windows 终端可将 `python3` 换为 `py -3`。端口占用时给服务命令加 `--port 4174`。须通过 HTTP 启动，不能直接双击 `frontend/index.html`。

## 功能模块

| 模块 | 当前职责 | 主要文件 |
| --- | --- | --- |
| 身体与魂穿 | 输入、目标选择、身体切换、镜头过渡、暂停与存档 | [main.js](frontend/src/main.js)、[species.js](frontend/src/species.js) |
| 世界与尺度 | 岛屿、地形、水域、实体布置与承载关系 | [world.js](frontend/src/world.js)、[anchors.json](data/anchors.json) |
| 碰撞与活动边界 | 包围盒碰撞、滑动、相机避障与脱困 | [collision.js](frontend/src/collision.js) |
| 感知与声音 | 身体视觉滤镜、视野参数、合成环境声与鸟叫 | [main.js](frontend/src/main.js)、[audio.js](frontend/src/audio.js) |
| 环境互动与文字 | 草弯折、鸟鱼反应、注视鸟叫与文字触发 | [interactions.js](frontend/src/interactions.js)、[interactions.json](data/interactions.json)、[dialogue.json](data/dialogue.json) |
| 模型与资产槽 | 程序占位、GLB 替换、模型变体、远景模型与装饰槽 | [assets.js](frontend/src/assets.js)、[实体配置](data/entities.json) |
| 数据与验证工具 | 从设计数据生成运行配置，执行文档、源码与隔离浏览器检查 | [数据说明](data/README.md)、[前端运行说明](frontend/README.md) |

`data/` 是设计数据的唯一来源；运行配置由同步脚本生成。模块已接入不代表每个设计字段都已生效，具体差距见实现审计。

## 开发状态

当前原型已接通基础探索、全部身体种类、尺度往返、感知切换、环境互动和浏览器存档。仍有以下工作：

- 魂穿目标排序、可见性判断、准备态与完整回滚尚未完全满足设计合同。
- 模型全部为程序占位，尚未导入真实 Lux3D 资产；环境声为合成占位，部分身体音景仍待实现。
- 文字回应中的引文版本、译文与署名仍待核对。
- 真人试玩、正式资产验收与目标设备性能测试尚未完成，已有自动检查不能替代这些验收。

详细状态见 [实现审计](docs/11-prototype-audit.md) 与 [变更记录](project/CHANGELOG.md)。本分支为 `codex/project-initiate` 初始化候选，首次完整工程 PR 合入前，不能将其内容视为 `main` 已有内容。
