## 从工作区根目录运行

```sh
python3 frontend/serve.py
python3 project/sync_runtime.py   # 改了 data/ 之后
python3 project/validate_docs.py
```

第一个命令启动当前工作区的前端，地址 `http://127.0.0.1:4173`。第二个由 `data/` 生成运行配置，第三个只校验规范与数据，不代替进游戏验收。

## 每次迭代

1. 从 TASKS 选任务，填写关联规则、数据、QA 与负责人。
2. MUST 变更按团队规则共同确认并记录在 09；TUNABLE 调整记录旧值、新值、理由和试玩结果。
3. 同步修改实现与对应数据／文档，不把样例或未取得的资产写成已完成。
4. 运行受影响检查和实际验收；每天保留一个可运行构建，记录版本与已知限制。
5. 在 CHANGELOG 记录结果。未完成工作保留为未完成，延后需求进入 DEFERRED。

具体成员姓名、最终引擎、截止日期、目标测试机与主办方条款待填写，角色分工见 TASKS。本轮没有向外部平台发布或提交。
