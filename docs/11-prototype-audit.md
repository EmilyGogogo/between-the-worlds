## 现状

- 从根目录按 README 启动 `frontend/serve.py` 可运行当前前端，默认地址 `http://127.0.0.1:4173`；本文件不保证此端口随时有服务。旧十四种身体快照属于历史，`.work/` 与旧输出不属于当前 Git 仓库内容。
- 运行配置全部来自 `data/`：`main.js` 启动时调用 `loadRuntimeConfig()`，键位、身体、感知、碰撞、资产槽、回应文字和可调数值都从 `game.json`／`manifest.json` 读取。
- 所有模型仍是程序化占位，没有真实 Lux3D 产物。
- 既有自动检查覆盖开发用 Mac 及 Windows 11 的隔离 Chrome；历史结果见 CHANGELOG，原始日志已删除。这不是非开发机试玩，也没有目标设备帧率结论。

## D-019 制作顺序建议

在不减少既有 MUST 或扩大范围的前提下，按依赖推进：先验证人开场与目标选择，再验证身体差异和岛的往返、完成一条真实资产链，最后集中真人试玩、非开发机和性能验收。工作可按依赖并行；这是排期建议而非工作量估算或新的发布门槛。D-024 入场提示已获创作者授权并接入，实际理解与遮挡需试玩；R-04／R-13 的具体方案先试玩评审，不能把提案标成已完成。
