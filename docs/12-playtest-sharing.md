## 已交付的电脑试玩包

历史文件名为 `万物之间_电脑试玩包.zip`，当时约 512 KiB。2026-11-01 协作交接时，该 ZIP 已不在本地输出目录；本文保留当时的交付记录，不提供失效下载链接。最新版完整开发源码与协作方式见 [14](14-team-collaboration.md)。当时接收者在电脑上解压，用 Chrome 或 Edge 打开其中的 `万物之间.html`，点击「进入旷野」，无需 Python、Node、服务器或联网加载资源；手机与微信内置浏览器未验收完整键鼠玩法。

开发者可运行 `python3 project/export_playtest.py --source .work/share/site` 从本次保留的源快照重新生成。脚本只改变分发方式，将现有脚本、CSS、图标和空模型清单内嵌到单个 HTML。原始 `frontend/index.html` 仍须通过本地 HTTP 服务打开；已生成的 HTML 可以直接双击。若源代码新增配置请求或清单中加入外部模型，导出器会停止并要求先补齐打包。

历史构建清单 `输出/试玩分享/playtest-build.json` 只在原开发工作区保留，不随新版源码包分发。旧分享包包含 Three.js MIT 许可证与现有资产来源说明，玩法仍含十四种身体、同行与星球等实验内容，仅用于当时原型试玩，不是正式三种身体 Demo；未使用真实 Lux3D 产物。

## 本机与临时在线访问

本机网页地址为 `http://127.0.0.1:4173/`。这个地址只指向打开它的那台电脑，不能作为微信对外分享链接。在线分享尝试使用仅含网页所需静态文件的独立目录，没有暴露整个项目根目录。

临时公网通道需要本机保持开机、联网且不休眠，服务与通道进程需要持续运行，重新连接后地址可能变化。两次匿名 SSH 通道分别因连接超时和远端主动关闭而失效；Cloudflare 通道因边缘连接 TLS 握手失败未建立可用访问。公网曾能返回与原版相同的入口 HTML，但没有完成可玩验收，浏览器最终收到 `no tunnel`。这些失效地址不作为交付链接，已停止失败通道。当前交付为已验证的离线包。
