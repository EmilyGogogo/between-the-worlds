# 万物之间 · 项目简报

版本：0.3-review · 2026-11-01。规则入口：[01 全局规则](01-global-rules.md)。

**一句话**：在一座岛上成为草、树、人、狗、鸟、鱼、岩石，看见、听见和行动的方式随之改变；直到某一刻，你意识到脚下的大地本身是一座岛，并成为了它。

| 项目 | 本次 Demo |
| --- | --- |
| 核心思想 | 人只是万物中的一种存在；换一个尺度，重要的事也会改变 |
| 目标玩家 | 愿意观察自然、自由尝试的电脑端玩家；不需要游戏或哲学背景 |
| 核心体验 | 观察目标 → R 魂穿 → 身体、感知和尺度随之改变 → 继续探索或回到小尺度 |
| 核心时刻 | 以人或鸟在岛上活动，在岸边或高处看出脚下是一座岛，成为岛，看到群岛与海（G-07） |
| 体验时长 | 3–5 分钟能完成一次 草 → 身体层 → 岛 → 回到小尺度 的往返；之后可以一直漫游 |
| 世界 | 一座主岛（晨雾草地、林地、山湖、岩丘、岸线、近海）＋三座邻岛＋海 |
| 可魂穿实体 | 草、树、动物（人、狗、鸟、鱼）、岩石、岛屿；当前 13 种，分 4 个尺度层，见 [04](04-entity-catalog.md) |
| 感知差异 | 每种动物看到、听到的世界不同，例如狗看到黑白世界并听得更远 |
| 操作 | WASD、鼠标、Shift、R、Esc；没有跳跃和升降键，鸟和鱼随视线上下 |
| 美术与声音 | 自然比例、可信材质、柔和光雾、克制留白的构图；环境声优先，极少的中文回应 |
| 平台 | 电脑浏览器、键鼠、单人；当前实现为 Three.js，正式引擎待定（R-05） |
| 制作条件 | 3–4 人、2–3 周；每人 588 美元算力支持为创作者提供的信息，适用范围未核实 |
| Lux3D 作用 | 所有可魂穿实体和环境都预留资产槽，用 Lux3D 生成、Blender 修整后替换代码生成的占位；至少一项核心资产要有完整证据链 |
| 交付 | 可运行链接或构建、真实运行视频、源码、报告、资产来源与过程材料，见 [10](10-submission-checklist.md) |

本次不做星球、太阳、房屋、花、同类同行、复杂生态、多人和运行时生成玩法（G-05）。

## 当前状态

前端已按本稿跑通（2026-11-01）：13 种实体、尺度往返、人在岸边成为岛、狗的黑白视野、禁止穿模、鸟鱼随视线升降，配置全部来自 `data/`。所有模型仍是占位，尚无真实 Lux3D 资产；真人试玩与帧率尚未验收。详情见 [11 原型审计](11-prototype-audit.md)。
