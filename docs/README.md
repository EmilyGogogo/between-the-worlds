# 万物之间 · 文档入口

版本：`0.4-review` · 日期：2026-11-01。这里是团队首次共同制作的设计基准；保留稳定编号，不另复制一套“最新版”。

当前范围是群岛与草、树、人、狗、鸟、鱼、岩石、岛屿 8 个类别，当前 11 个种类。干净开局是人；魂穿只在相邻尺度档之间进行（D-021），逐级长大到巨岩或成为鸟飞高后，看见可辨认的岛并选中涟漪，可按 R 成为岛。**规则、评审、实现和验收状态分别记录；MUST 不等于已实现，自动检查不等于真人验收。**

2026-11-02 的 D-019 补充了目标选择、返回、镜头和首次岛屿回应的边界及试玩方法；相关实现缺口见 11，不代表现有原型已经满足新合同。

## 唯一来源

| 内容 | 唯一来源 | 生成或引用 |

上述 JSON 均有运行时接入，但不表示所有描述字段都被执行。例如 `uniqueAbility.text` 是设计说明，不会自动生成能力；资产来源、评审状态也不决定运行行为。已支持字段的改动流程：改 `data/` → 运行同步脚本 → 文档校验 → 隔离浏览器检查及受影响 QA。新增算法仍需实现；现状与缺口见 [11](11-prototype-audit.md)。启动方式以根目录 README 为准。

## 怎么一起 review

评论用编号，例如“P-13：涟漪改为出现在岸线上”“B-04：鸟的饱和度再高一点”“W-07：主岛缩小一半”。先改规则，再改数据和验收条目。

变更优先级：创作者／团队新确认的决定 → 本目录规范 → `data/` → 实现与测试。批准的行为由规则约束，数值只在数据中维护；发现矛盾时对照 09 追溯并修正，不自动认为代码或数据覆盖了 MUST。待评审建议不因出现在数据或原型里就变成已批准规则。团队确认和 PR 合并审核是两项记录：Emily 审核 PR 不自动补齐所有玩法规则的团队确认。
