# 决策记录与评审队列

## 当前有效的决定

### D-013：交接最新版完整游戏，按种类并行制作并经 GitHub 合并测试

日期：2026-11-01。来源：创作者明确要求把最新版整个游戏发给同事，每人负责固定种类的 3D 资产、共同美化岛屿，最终在 GitHub 合并测试。

执行：整理当前 `0.4-review` 完整源码协作包、跨平台启动入口、种类分工草案、共享数据集成约定、PR / 任务模板和自动检查工作流。沿用现有资产合同、数据唯一来源与 QA，不修改玩法 MUST 或扩大类别范围。成员姓名、仓库地址、实际资产生产与远端运行结果待填写；本轮不把计划记为模型已导入或 GitHub 已完成。

影响：[14 协作指南](14-team-collaboration.md)、[15 检查记录](15-collaboration-validation.md)、根目录 README、project 检查 / 导出工具与 `.github/`。用户已授权本地准备与源码交接，无需就同一范围重复确认。

### D-006：首版范围改为群岛与五类实体（取代 D-001）

日期：2026-11-01。来源：创作者明确指示——“首版仅一块小岛、约三种身体”不好，也和试玩网页不符；要有“在岛上活动时看见岛成为岛”的体验。

决定：世界是一座主岛加周边群岛与海；可魂穿类别限定为草、树、动物（人、鸟、鱼、狗）、岩石、岛屿；当前 13 种（G-04）。新增 G-07 核心时刻、G-08 数据驱动扩展、W-05 每层都有可进入的目标、W-06 尺度隐藏但状态保留、P-12 尺度关系、P-13 承载整体。星球、太阳、房屋、花延后。

影响：原“草、鱼、鸟三种身体”“潮汐花园”方案撤回；G-01 改为按类别验证独特能力或感知；QA 清单重写为 QA-01～QA-39（0.4 增至 QA-45）。

### D-007：删除跳跃与升降按键（原 I-02）

日期：2026-11-01。来源：创作者明确指示“删除此功能”，所指为原 I-02“Space 只对支持轻跃／上升的身体生效；Ctrl 只对支持下降的身体生效”。

决定：Space 与 Ctrl 不绑定、不提示；飞行和游泳身体沿镜头俯仰方向上下移动，地面身体贴地，没有跳跃（新 I-02）。原评审项 R-03（鱼的升降开关）随之关闭。

### D-008：禁止穿模，大型实体必须绕行

日期：2026-11-01。来源：创作者明确指示。

决定：新增 M-01～M-03、M-05。实心实体（树、岩石、巨岩、岛、人、狗等）不能被穿过，接触时沿表面滑开；草是柔性实体，可以被经过但要有弯折反馈；同层大身体互不重叠；相机和魂穿落点同样不能穿模。数据字段：`collision.solid` 与 `collision.passPolicy`。

### D-009：动物的感知档案

日期：2026-11-01。来源：创作者明确指示——不同动物展示的世界在视觉和听觉上不同，例如狗看世界是黑白的。

决定：新增 B-04、B-05、P-14。每种动物有视觉与听觉档案；狗黑白、听得更远是创作者指定；鸟、鱼的具体参数由创作者 2026-11-01 确认（R-07）。这些是艺术表达，不宣称为科学还原。

### D-010：所有实体预留 3D 资产槽

日期：2026-11-01。来源：创作者明确指示——实体都准备用 Aholo Lux3D 生成；游戏可以先用代码生成，但每个实体最终都要有接入 3D 资产的入口；后续会不断加入更精细的模型替换粗糙的占位。

决定：新增 L-04～L-06。每个可魂穿种类与环境部件都有资产槽，`data/entities.json` 是唯一来源，经 `sync_runtime.py` 生成运行配置；替换资产不改玩法代码。合同见 [06](06-lux3d-asset-pipeline.md)。

### D-012：可扩展框架、互动与声音入口

日期：2026-11-01。来源：创作者明确指示——补上资产槽缺口；进入游戏后无法打开声音；现在可玩性太低，后续要大量增加实体、种类和互动，十几个实体只是初版，入口必须留好，做成可扩展的，避免每次迭代影响技术框架。

决定：
- 资产：一个槽可挂多个变体模型（按权重、按个体 ID 固定分配）与远景模型；成片草地、湖底卵石改为装饰槽，可换成 GLB 实例（L-04、L-07）。
- 布局：`data/anchors.json` 成为运行时世界布局，个体与成片布景都在数据中（W-08）。
- 类别：类别清单移入 `entities.json` 的 `categories`；占位外形按类别注册，未知类别显示通用占位；新增种类可用 `project/new_species.py` 生成（G-08）。
- 互动：新增 `data/interactions.json` 与 X-01～X-04；首批四条：草弯折（原有）、鸟飞起、鱼四散（方案）、注视时鸟叫（方案）。
- 声音：进入世界时默认开启；顶栏按钮在暂停层之上可点；暂停菜单增加“环境声”开关；记住偏好（A-02 修订）。

影响：01、04、05、06、07、08（QA-40～QA-45）、11、13（新）；运行时代码新增 `interactions.js`；存档升到 v4，旧存档被忽略。鸟飞起、鱼四散、鸟叫三条互动的具体手感待试玩确认（R-13）。

### D-011：世界回应改用哲学家原句

日期：2026-11-01。来源：创作者明确指示——原回应文案“不够哲学，太白话”，替换为哲学家说过的原句，大致符合游戏哲学和实体角色即可。

决定：14 条回应全部改为原句，出自庄子、老子、孔子、帕斯卡、赫拉克利特、维特根斯坦、福柯；人第一次成为岛时出现福柯《词与物》结尾的“沙上之脸”。逐字引用、不改写；U-03 字数上限对引文放宽到 18 字（福柯一句为 17 字），原创文字仍为 8–16 字。外文句子的中文为常见译法，定稿时按选定中译本核对（TASK-CONTENT）。署名只放暂停菜单是方案，待团队确认。

影响：`data/dialogue.json`、07、U-03、LICENSES、校验脚本。原 13 句原创文本与 R-12 的改写句不再使用。

### D-002：文档与数据成为迭代基线（仍有效）

### D-005：按创作者要求分享现有网页原型（历史）

日期：2026-10-31。来源：创作者明确要求找到此前的「万物之间」游戏页面，通过微信发给朋友，让朋友在自己的电脑上查看，并指示继续处理。

执行：保留现有玩法，导出可解压后直接打开的单 HTML 试玩包；尝试临时公网访问。仅分享创作者已看到的旧探索原型，不作为正式比赛提交构建，不把十四种身体等延后内容加入新 Demo 范围。检查只覆盖实际记录的启动、移动和暂停等行为；非开发机完整试玩、Lux3D、新 Demo 验收保持未完成。具体产物、限制与检查见 [原型分享](12-playtest-sharing.md)。
