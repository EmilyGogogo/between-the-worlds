# QA 与完成标准

版本：0.4-review · 2026-11-01。**下列条目全部待验收，本轮没有运行游戏测试。** 旧原型的“37 项检查通过”覆盖的是旧范围，不能用来勾选本清单。

## 测试记录头

每轮填写：构建 ID／代码版本、规范版本、数据版本、日期、测试者、电脑型号、CPU／GPU、内存、系统、浏览器及版本、窗口分辨率、DPR、冷／热启动、是否联网、音频状态。结果记为通过／失败／阻塞，附截图、录像、性能日志或复现步骤；不写无证据的“应该通过”。

## 范围与新手

- [ ] **QA-01 / G-04、G-05**：从干净启动遍历全部区域，可魂穿种类恰好是 `entities.json` 中的 13 种；没有星球、太阳、花、房屋、同行入口。
- [ ] **QA-02 / G-06**：至少 3 名未参与开发的试玩者，无口头指导，从点击开始到首次有效 R 魂穿都在 30 秒内；记录每人用时与卡点。
- [ ] **QA-03 / G-02、G-07**：无指导的试玩者在 5 分钟内完成一次 草 → 身体层 → 岛 → 回到小尺度 的往返；无任务提示、无倒计时。

## 选中与魂穿

- [ ] **QA-05 / P-01～P-05**：把目标分别放在视野内、镜头后、范围外、完全遮挡、部分可辨认、水面完全遮挡等状态，逐项验证选中与取消。
- [ ] **QA-06 / P-03、P-04**：两个目标靠近时只有一个涟漪；看向 A，不会因为 B 的优先级而进入 B。
- [ ] **QA-07 / P-11**：在近似目标之间轻微晃动鼠标不闪烁；明显转向另一个目标会切换；旧目标非法时立即清空。
- [ ] **QA-08 / P-06**：涟漪出现后、按 R 之前让目标移走或被遮挡；R 重新验证并保留原身体。
- [ ] **QA-09 / P-07、P-10、P-14**：录制 草↔人、人→岛、岛→巨岩、狗↔鸟、鸟↔鱼 的过渡；在设定时长内连续完成，没有硬切、黑屏、双重主体或镜头穿模；感知档案在过渡中逐渐变化。
- [ ] **QA-10 / P-06**：过渡中持续按 WASD、Shift、R，不发生位移或第二次魂穿；落位后没有积压输入；Esc 暂停与恢复正确。
- [ ] **QA-11 / P-08、L-03**：注入模型 404、解析错误、超时、占位也失败、落点失效；都在有限时间内进入占位或回到原身体，输入锁解除。
- [ ] **QA-12 / W-02**：往返魂穿 20 次，原实例 ID 与位置正确，实例数量不增长，任意时刻只有一个受控主体；过渡中刷新不会恢复成损坏状态。

## 发布判定

新范围的 MUST 验收项全部通过（QA-01～QA-45）、有证据、无阻断问题后才能提交。60 FPS 没达到但最低指标达标时，记录性能余量，不宣称稳定 60 FPS。旧测试中仍有价值的部分（模型加载、骨架克隆、单主体控制、存档恢复）可以保留；同行与星球的测试不再作为发布要求。

本轮只执行了文档与数据一致性校验，不是以上玩法验收。
