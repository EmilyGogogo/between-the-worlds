# 操作与镜头

版本：0.4-review · 2026-11-01。键位来源：[input-map.json](../data/input-map.json)；身体参数：[entities.json](../data/entities.json)。

## 输入合同（I-01～I-04，MUST）

| 输入 | 行为 | 条件 |
| --- | --- | --- |
| W/A/S/D 或 ↑/←/↓/→ | 第三人称 W 向画面前方前进；A/D 转向画面左／右并沿目标方向移动；S 转身约 180° 后前进。单次持续按住锁定方向，不连续绕转。第一人称 W 前进、A/D 横移、S 后退 | 所有身体统一；受活动区与碰撞限制；两组等效 |
| 鼠标 | 第三人称环视；第一人称转动视线、观察目标 | 指针锁定；失败时按住拖动 |
| V | 切换第一／第三人称 | 正常探索；长按只切一次，暂停与过渡中忽略 |
| Shift | 加速 | 不改变能力、边界和碰撞 |
| R | 魂穿当前主目标 | 当帧再验证合法，且不在过渡中 |
| Esc | 暂停／继续 | 暂停移动和过渡计时；菜单显示操作、继续、重新开始、声音开关 |
| Space、Ctrl | **不绑定** | 创作者 2026-11-01 删除跳跃与升降键（D-007） |
| E | 保留 | 本次不绑定，不显示任何提示 |

**上下移动**：飞行（鸟）和鱼沿镜头俯仰方向移动——抬头按 W 向上，低头按 W 向下。人入水时在水面游泳，其他地面状态贴地；没有跳跃。岛屿在海面上漂移。数据字段：`verticalControl`。

菜单打开或浏览器失去焦点时清空按键状态，避免松键丢失导致持续移动。R 长按只触发一次。

### 入场与操作速查（D-024）

开始按钮下解释移动键、V 切换视角、指针隐藏及 Esc 暂停释放；继续存档也显示。探索中右下始终保留三行紧凑速查（移动／环视、R 魂穿与 V 当前视角、Shift／Esc），鸟鱼补充一行升降输入。完整操作放在暂停菜单。提示不要求悬停，也不增加任务或路线指令。

入场镜头未结束时显示“镜头到位后即可移动”，移动与魂穿提示变淡。指针实际锁定成功后，短暂说明“指针已隐藏 · Esc 显示鼠标”；时长来自 `pointerHintSec`（6 秒初值，暂停和过渡不计时）。未锁定时速查改为“左键拖动环视”，移动不依赖锁定。拖动结束、取消、失去捕获或焦点都清理拖动状态。

失焦时自动暂停，菜单说明“离开画面，已为你暂停”；返回不会自动恢复或捕获指针。点击继续会聚焦画面并请求锁定；Esc 继续若未锁定则显示拖动方式。入场与魂穿过渡不积压移动，结束后须重新按键。同一方向同时按住 WASD 与方向键时，松开其中一个仍保留另一个输入。

每次有合法主目标时都显示紧凑提示“R 成为［目标名］”，随目标切换更新名称；目标失效、暂停或进入过渡时隐藏，再次选中合法目标即恢复。魂穿成功次数和存档中的旧 `hints.r`／`hints.possessed` 均不影响提示，操作速查也不随存档隐藏。

## 镜头

默认第三人称，完整主体是第三人称的正常构图约束（C-01）。镜头可以看向身体前方和可达环境，让玩家能看见目标；不能为了瞄准把当前身体裁出画面。避障临时迫使镜头靠近时，优先保证相机不穿模和玩家仍能操作，主体可以短暂不完整；离开遮挡后平滑恢复完整构图（D-019）。

### 双视角（D-029）

第三人称以按键开始时的屏幕方向为目标，身体以 `turnSpeedDegPerSec` 限制转速。W／↑ 向画面前方前进；A／← 与 D／→ 分别转向画面左／右并沿目标方向前进；S／↓ 先转身约 180°，转向期间不倒退，转到目标方向后再前进。同一次持续按键锁定目标方向，不重复累积转向；松开或换方向后再按，以当前画面重新确定目标。镜头的实际环绕位置与注视方向在同帧随身体实际转角跟转；身体原有的活动路线朝向不会被当作玩家转角，按键时读取当前画面实际方向；身体和镜头均按该实体转速限速，完成对齐后才沿锁定方向前进；所有身体共享这套第三人称操作，岛的镜头跟随其朝向但不旋转整座地形及其居民。第一人称保持镜头视线为基准：W 前进、A/D 横移、S 后退，鼠标控制视线。配置 `cameraModes.third_person.followBodyTurn` 为 true。

所有第三人称统一使用人类全彩、基准 FOV 和视觉档案；尺度雾与真实水下环境仍保留。第一人称相机位于当前身体眼位，鼠标控制视线，A/D 平移、S 后退；地面身体可以仰视但不会离地，鸟鱼仍沿视线升降。隐藏自己的视觉模型以免挡住镜头，保留碰撞与承载物；岛保留自身地形。

第一人称使用当前身体的视觉与 FOV：狗黑白；海鸥明亮饱满偏暖、远处灰雾更淡；银斧鱼以水下蓝绿为底略偏蓝、看得较远；七彩神仙鱼略偏暖、看得近；鱼视野更宽。两种鱼在第一人称下用自己的水色（`perception.vision.underwaterFog`：水下雾色、浓度与透过水面看到的天空色），第三人称保留共用的水下效果。第一人称镜头（`camera.firstPerson.lens`，2026-11-14）：两种鱼是广角鱼眼，画面四角以缓慢的水波状边缘淡入当前水色，不用黑边；海鸥是铺满屏幕约 110° 的宽视野，边缘轻微弯曲、稍虚。镜头只改画面，目标选择仍按原相机；总强度 `tuning.firstPersonLensScale`（0 关闭）。第一人称身体运动（`camera.firstPerson.motion`）按模型动画实时读取：海鸥眼位随 `Flap` 翅尖高度轻微起伏、点头，`Glide` 只缓慢漂浮，只抬高不压低；两种鱼随游动时头部的实际摆动左右摆头（神仙鱼慢而柔、银斧鱼小而碎），不上下、不改移动方向；魂穿过渡中不晃，总强度 `tuning.firstPersonMotionScale`（0 关闭，防晕动）。会游泳的身体第一人称眼位始终在水面下至少 0.12 m。银斧鱼 `restPitchDeg` -12：进入第一人称或在第一人称魂穿到它时视线先上抬 12°，之后鼠标照常控制。转身速度银斧鱼 260°/s、七彩神仙鱼 130°/s。自身模型在第一人称继续隐藏（“看见自己”本轮不做）。听觉在两种视角中都随身体变化。V 切换视觉档案时按 `perceptionCrossfadeSec` 淡化；魂穿使用完整过渡时长。V 不在暂停或过渡期间触发，不积压长按输入。视角在魂穿和 v4 存档恢复后保持，旧存档默认第三人称。配置唯一来源为 `entities.json.cameraModes` 与各身体的 `camera.firstPerson`，键位来源为 `input-map.json`。

每个尺度层有自己的观察距离、雾距与运动节奏（C-06）。镜头前视、贴地、避障、雾浓度、阴影和焦点高度按层写在 `entities.json` 的 `scaleLayers`，代码不按层号写死：

| 层 | 镜头 | 雾与远景 | 节奏 |
| --- | --- | --- | --- |
| L0 草 | 贴地，数米外看见整株草摇曳 | 晨雾较浓，近处细节清楚 | 轻快细碎 |
| L1 身体层 | 数米到数十米；树的镜头更高更远 | 中等雾距；第一人称鸟的远景更清楚，鱼看得更近 | 各自的步态、振翅、摆尾 |
| L2 巨岩 | 数百米，看见山体与其上的林木 | 雾变淡，看见岛的一侧 | 缓慢厚重 |
| L3 岛 | 一千多米，看见整岛轮廓与群岛 | 雾很淡，海面和天空成为主体 | 漂移平稳 |

具体数值在 `entities.json` 的 `camera` 中，属于 TUNABLE。

## 相机避障（C-02）

从身体锚点到期望相机位置做体积检测；遇到地形、岩石、树或其他实心实体时缩短距离或调整环绕，解除遮挡后平滑恢复。不能只检查最终相机点是否在石头里。成为岛或巨岩时，相机同样不能进入邻岛或山体。

## 柔性边界与脱困（M-04、M-06、M-07）

| 身体 | 活动区 | 边界表现 |
| --- | --- | --- |
| 草、树、狗（植物与不会游泳的动物） | 只在陆地（D-036） | 走到水边停在岸上、沿岸滑行，不下水 |
| 人 | 陆地与水域 | 进入水域切换游泳并保持水面附近，出水恢复陆地状态（D-026） |
| 海岸岩石 | 陆地与浅水潮间带（R-08 已确认；涉水深度 3 米，D-036） | 涉水深度按实际水深计；在水中贴着河底／湖底，不浮在水面；超过 3 米停在原处、沿边滑行 |
| 鱼 | 所在水体（湖或近海）内 | 接近水面、水底、岸边时减速贴边；是否可以短暂跃出水面待评审（R-10） |
| 鸟 | 主岛空域，高度不超过上限（初值 180 米） | 接近上限和水平边界时减速、柔和回引 |
| 岛 | 群岛之间的海面 | 不与邻岛重叠；接近外海边界时减速 |

不用透明墙、死亡或惩罚表达边界。

脱困必须区分静止观察、正常边界与真正卡住（M-06）。**当前实现与待评审方案（R-04）**是仅在有移动输入、连续约 2 秒位移小于阈值且碰撞诊断确认陷入或重叠时触发，并排除暂停、过渡和正常边界减速；单纯“2 秒没动”不算卡住。先尝试短距离推出，不行再以轻微的镜头与环境过渡恢复到最近的有效位置；恢复后给 1 秒保护，避免循环。具体触发条件与手感待试玩确认，这是技术恢复，不是失误惩罚。

## 当前实现
